# Day 12 - Console Tab

## Purpose

The Console tab displays JavaScript errors, warnings, and log messages generated by the browser.

---

## What Can Be Found?

- JavaScript errors
- Warning messages
- Console logs
- Failed scripts

---

## Example Error

```
GET /inventory.html 404 (Not Found)
```

---

## Why QA Engineers Use the Console

- Identify JavaScript errors
- Attach console logs to bug reports
- Help developers reproduce issues
- Verify browser warnings

---

## Best Practice

Always check the Console when a feature behaves unexpectedly before reporting a bug.
