# Day 12 - Elements Tab

## Purpose

The Elements tab allows QA Engineers to inspect and analyze the structure of a webpage.

---

## What Can Be Inspected?

- HTML elements
- CSS styles
- DOM structure
- Buttons
- Images
- Input fields
- Hidden elements

---

## Common QA Uses

- Verify UI components
- Inspect page layout
- Check missing or hidden elements
- Confirm button text
- Validate CSS styling
- Test responsive layouts

---

## Example

While testing SauceDemo, I inspected the Login button using the Elements tab to view its HTML structure and applied CSS classes.

---

## Key Takeaways

The Elements tab helps QA Engineers investigate UI-related issues without modifying the application permanently.
