## What I Learned

Today I learned how APIs allow different software applications to communicate with one another. I also learned how to use Postman to send a GET request and inspect the API response.

I now understand the purpose of common HTTP methods such as GET, POST, PUT, PATCH, and DELETE, as well as how to interpret HTTP status codes and JSON responses.
