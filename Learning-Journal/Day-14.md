## Challenges

Initially confused about the expected success status codes for PUT and DELETE requests.

After reviewing the lesson, I learned:

- POST → 201 Created
- GET → 200 OK
- PUT → 200 OK
- PATCH → 200 OK
- DELETE → 200 OK or 204 No Content

---

## Key Takeaways

- POST creates new resources.
- PUT replaces an entire resource.
- PATCH updates specific fields.
- DELETE removes a resource.
- API testing validates backend functionality independently of the user interface.
