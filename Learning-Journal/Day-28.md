## 🧠 Key Learning

One of the most important lessons today was understanding the difference between the major testing techniques.

### Equivalence Partitioning

Divide input data into groups where the system should behave similarly.

### Boundary Value Analysis

Test values at and around the boundaries of an input range.

### Decision Table Testing

Test combinations of conditions and their expected results.

### State Transition Testing

Test how the system moves from one state to another after an event.

### Error Guessing

Use testing experience to predict where defects may occur.

### Exploratory Testing

Explore the application while learning, designing tests, and executing tests.
