## 🧠 Key Lessons

One of the most important things I reinforced today was the difference between test techniques.

### My technique memory map:

```text
EP = Groups
BVA = Boundaries
Decision Table = Combinations
State Transition = States
Branch Testing = Code decisions
Error Guessing = Experience
Exploratory Testing = Exploration
```
I also reinforced:
Severity = Impact
Priority = Urgency

Another important lesson was that a defect should normally be reopened after a failed retest, rather than creating a duplicate defect.
