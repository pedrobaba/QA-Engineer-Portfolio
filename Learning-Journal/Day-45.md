# Day 45 — Learning Journal

## Topic

Cross-Browser Testing

## What I Learned

Today, I learned how to compare the behavior of a web application's functionality across Chrome, Firefox, Edge, and Safari.

I practiced creating a browser compatibility matrix, recording expected and actual results, investigating JavaScript errors with the Console, and checking whether API requests were sent using the Network panel.

I also learned that a browser-specific failure does not automatically prove that the browser or frontend is the root cause.

## Practical Exercises Completed

* Created a hypothetical browser compatibility matrix.
* Recorded expected and actual Login results for four browsers.
* Classified a Firefox Login failure using Console and Network evidence.
* Compared a client-side failure scenario with a separate API/server error scenario.
* Practiced writing a browser-specific bug report.
* Made a release recommendation based on the exercise evidence.

## Challenge

My initial instinct was to classify a browser-specific failure as a backend defect without enough evidence.

I learned to investigate the request flow first and distinguish observed symptoms from confirmed root causes.

## Key Lesson

**Follow the evidence instead of assuming the root cause.**

## What I Need to Improve

* Execute compatibility checks on a real application.
* Capture authentic screenshots and diagnostic evidence.
* Record verified browser versions and operating systems.
* Improve defect severity justification.
* Practice cross-browser testing beyond the Login scenario.
