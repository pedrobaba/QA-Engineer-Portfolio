# QA Engineering Learning Resources

## Day 45 — Cross-Browser Testing

### Learning Focus

Cross-browser testing involves checking whether a web application behaves consistently across different browsers. This day's practical focused on testing SauceDemo in Google Chrome and Mozilla Firefox.

### Website Tested

* [SauceDemo](https://www.saucedemo.com/)

### Browsers Used

* Google Chrome
* Mozilla Firefox

### Practical Testing Areas

* Login functionality
* Add-to-cart functionality
* Checkout information and overview
* Order completion and confirmation
* Shopping cart consistency
* Responsive layout at a viewport of 390 × 844 pixels

### Testing Results

The tested scenarios passed in both Chrome and Firefox based on the observations recorded during the practical session.

No compatibility defects were observed in the tested scenarios. These results apply only to the workflows and viewport checked; they do not establish that the entire application is defect-free.

### Key Concepts Reviewed

* Cross-browser compatibility
* Functional consistency across browsers
* Shopping cart validation
* Checkout workflow validation
* Responsive layout inspection
* Evidence-based defect reporting
