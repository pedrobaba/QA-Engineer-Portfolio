# Day 69 — Learning Journal

## Topic
End-to-End Manual Testing Project

## What I Learned Today

Today, I studied the complete end-to-end manual testing workflow using SauceDemo as a practice application.

I learned how to define project scope, identify test scenarios, write detailed test cases, understand test execution statuses, document defects, collect evidence, perform regression testing and prepare a test summary report.

I also learned the importance of project closure and lessons learned.

## Key Concepts

- Testing scope.
- End-to-end test scenarios.
- Test case design.
- Test execution.
- Passed, Failed, Blocked and Not Run.
- Test execution metrics.
- Bug reporting.
- Severity vs priority.
- Test evidence.
- Retesting vs regression testing.
- Test summary reports.
- Test closure.

## Important Things I Learned

One important lesson was that a test failure does not automatically mean there is a product defect. The tester must investigate the failure and determine whether it is caused by the application, environment, test data or execution mistake.

I also learned that retesting confirms whether a specific defect has been fixed, while regression testing checks whether existing functionality continues to work after a change.

## Interview Preparation

I practised explaining:

4. The difference between retesting and regression testing.

6. The activities involved in test closure.
