## Lessons Learned

I learned that collecting screenshots is not enough. Evidence must be organised, properly named and connected to the relevant test case or bug report.

I also learned that a screenshot showing an HTTP 200 response does not automatically prove that an API response is correct.

The response must still be checked against the expected behaviour.
