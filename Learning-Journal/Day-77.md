# Day 77 — Learning Journal

## Topic: Introduction to Automation Testing

### What I Learned

Today, I was introduced to automation testing and how it fits into the QA engineering process.

I learned that automation testing uses scripts to execute test cases and verify application behaviour. I also understood that automation does not replace manual testing because both approaches serve different testing purposes.

I explored Playwright as the browser automation framework I will use for my practical automation learning.

I learned how automation frameworks organise test scripts, configuration files, test data, reusable page actions, and reports.

I was also introduced to Page Object Model and the Arrange–Act–Assert pattern.

Another important lesson was understanding Playwright's architecture, including browsers, browser contexts, pages, locators, assertions, fixtures, and reporters.

Finally, I reviewed the JavaScript concepts required for automation, particularly async/await, promises, functions, arrays, objects, and variables.

### Practical Knowledge Gained

I can now explain:

- The difference between manual and automation testing.
- Why automation is useful for regression testing.
- What an automation framework does.
- The purpose of Page Object Model.
- How Arrange–Act–Assert organises a test.
- How Playwright interacts with a browser.
- The difference between headed and headless execution.
- Why asynchronous JavaScript is important in browser automation.
