## Key Concepts

### Authentication

> Who are you?

Authentication verifies the identity of a user or application.

### Authorization

> What are you allowed to do?

Authorization determines what an authenticated user is allowed to access or perform.

### API Key

A unique value used to identify or authenticate an application making API requests.

### Bearer Token

A credential commonly sent through the Authorization header to access protected API resources.
