# Day 70 — QA Portfolio Project: Planning

## Overview

Day 70 focused on planning a structured QA portfolio project using the SauceDemo e-commerce application.

The objective was to establish the project scope, identify users and critical workflows, select appropriate testing approaches, define test scenarios, plan test cases and data, identify tools, and organise the project deliverables.

## 1. Application Selection

**Selected application:** SauceDemo

SauceDemo was selected because it provides realistic e-commerce workflows suitable for practising manual functional testing.

Key features include:
- User authentication
- Product inventory
- Product sorting
- Shopping cart
- Checkout
- Order confirmation
- Logout

## 2. Project Objectives

The project aims to:

- Validate critical e-commerce user workflows.
- Verify authentication behaviour.
- Test product inventory and sorting.
- Validate shopping cart operations.
- Test checkout form validation.
- Verify order summary calculations.
- Identify and document defects.
- Collect supporting test evidence.
- Perform relevant regression testing.
- Produce a professional test summary report.

## 3. Project Scope

### In Scope

- Login and authentication
- Product inventory display
- Product names and prices
- Product sorting
- Add-to-cart functionality
- Remove-from-cart functionality
- Checkout form validation
- Order summary
- Order completion
- Logout and navigation

### Out of Scope

- Real payment gateway processing
- Actual bank or card transactions
- Production database testing
- Advanced load and performance testing
- Penetration testing
- Unsupported third-party integrations
