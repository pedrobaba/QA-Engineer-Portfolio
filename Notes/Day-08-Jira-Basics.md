# Day 08 - Jira Basics

## What is Jira?

Jira is a project management and issue-tracking tool developed by Atlassian. It is widely used by Agile teams to manage software development projects and track defects.

---

## Common Jira Issue Types

### Epic
A large feature that can be divided into multiple user stories.

### Story
Represents a user requirement or feature.

### Task
A piece of work that needs to be completed.

### Bug
An issue where the application's actual behaviour differs from the expected behaviour.

---

To Do
↓
In Progress
↓
Code Review
↓
Testing
↓

---

## Information in a Jira Bug

- Summary
- Description
- Environment
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Assignee
- Status
- Attachments

---

## Why QA Engineers Use Jira

- Report bugs
- Track bug status
- Assign issues
- Monitor Sprint progress
- Link bugs to user stories
- Collaborate with developers

---

## Benefits of Jira

- Easy issue tracking
- Supports Agile workflows
- Sprint management
- Team collaboration
- Project reporting

---

## Key Takeaway

Jira enables QA Engineers to efficiently manage defects, collaborate with development teams, and monitor software quality throughout the development lifecycle.
