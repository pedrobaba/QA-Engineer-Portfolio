# Day 09 - Acceptance Criteria

## What are Acceptance Criteria?

Acceptance Criteria are the conditions that must be satisfied before a User Story is considered complete.

They describe the expected behaviour of the feature.

---

## Example

User Story:

As a user,

I want to reset my password,

So that I can regain access to my account.

---

## Acceptance Criteria

1. The system should send a password reset link to the registered email.
2. The user should be able to click the reset link.
3. The user should be able to create a new password.
4. The user should be able to log in using the new password.
5. The old password should no longer work.

---

## Characteristics of Good Acceptance Criteria

- Clear
- Specific
- Testable
- Measurable
- Easy to understand

---

## Why Acceptance Criteria Matter

- Defines expected behaviour.
- Reduces misunderstandings.
- Helps developers.
- Helps QA write accurate test cases.
- Ensures quality before release.

---

## Key Takeaway

If a feature meets all Acceptance Criteria, it can be considered complete.
