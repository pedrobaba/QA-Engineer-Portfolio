# Day 09 - Requirement Traceability Matrix (RTM)

## What is RTM?

A Requirement Traceability Matrix (RTM) is a document that maps requirements to their corresponding test cases and test results.

Its purpose is to ensure that every requirement has been tested.

---

## Why RTM is Important

- Ensures complete test coverage.
- Tracks testing progress.
- Helps identify missing test cases.
- Supports regression testing.
- Improves project quality.

---

## Sample RTM

| Requirement ID | Requirement | Test Case ID | Status |
|----------------|------------|--------------|--------|
| RQ-001 | Login | TC-001 | Passed |
| RQ-002 | Add to Cart | TC-002 | Passed |
| RQ-003 | Checkout | TC-003 | Failed |
| RQ-004 | Password Reset | TC-004 | Passed |
| RQ-005 | Logout | TC-005 | Passed |

---

## Components of RTM

- Requirement ID
- Requirement Description
- Test Case ID
- Test Result
- Status

---

## Benefits

- Prevents missing requirements.
- Makes audits easier.
- Improves traceability.
- Ensures every feature is validated.

---

## Key Takeaway

An RTM helps QA Engineers verify that all software requirements are covered by test cases and tested successfully.
