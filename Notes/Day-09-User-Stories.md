# Day 09 - User Stories

## What is a User Story?

A User Story is a short description of a feature from the user's perspective.

It explains:
- Who needs the feature.
- What they need.
- Why they need it.

---

## Standard Format

As a <type of user>,
I want <goal>,
So that <benefit>.

---

## Example

As a customer,

I want to reset my password,

So that I can regain access to my account if I forget my password.

---

## Benefits of User Stories

- Easy to understand.
- Focuses on user needs.
- Encourages collaboration.
- Helps create test scenarios.
- Supports Agile development.

---

## QA Responsibilities

QA Engineers review User Stories to:

- Identify test scenarios.
- Create test cases.
- Verify Acceptance Criteria.
- Clarify unclear requirements.

---

## Key Takeaway

Every User Story should deliver value to the end user.
