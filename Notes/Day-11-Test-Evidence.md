# Day 11 - Test Evidence

## What is Test Evidence?

Test evidence is any proof collected during testing to support the outcome of a test case or bug report.

It helps developers reproduce and fix issues more efficiently.

---

## Common Types of Test Evidence

### 📷 Screenshot

Used for:
- UI issues
- Layout problems
- Missing elements
- Incorrect text

---

### 🎥 Screen Recording

Used for:
- Application crashes
- Unexpected behavior
- Navigation issues
- Reproducing bugs

---

### 📄 Console Logs

Used for:
- JavaScript errors
- Browser errors
- Frontend debugging

---

### 🌐 Network Logs

Used for:
- API failures
- Slow responses
- HTTP status codes
- Request and response analysis

---

### 📑 Error Messages

Useful for identifying:
- Validation failures
- System errors
- Backend issues

---

## Why Test Evidence is Important

- Helps developers reproduce issues.
- Improves communication between QA and developers.
- Speeds up bug fixing.
- Reduces misunderstandings.

---

## Best Practices

- Capture clear screenshots.
- Record all reproduction steps.
- Include timestamps when possible.
- Use high-quality evidence.
- Attach evidence to bug reports.

---

## Key Takeaway

A bug report without evidence is harder to investigate. Good evidence makes defect resolution faster and more accurate.
