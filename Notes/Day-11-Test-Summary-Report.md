# Day 11 - Test Summary Report (TSR)

## What is a Test Summary Report?

A Test Summary Report (TSR) is a document prepared after test execution that summarizes the overall testing activities and results.

It helps stakeholders decide whether the application is ready for release.

---

## Information Included in a TSR

- Project Name
- Testing Period
- Test Environment
- Number of Test Cases
- Passed Tests
- Failed Tests
- Blocked Tests
- Defects Found
- Major Findings
- Recommendation

---

## Sample Test Summary

**Project:** SauceDemo

**Testing Period:** 1 Hour

| Metric | Result |
|---------|--------|
| Total Test Cases | 25 |
| Passed | 22 |
| Failed | 2 |
| Blocked | 1 |
| Critical Bugs | 1 |

---

## Recommendation

The application is **not recommended for release** until the critical defect affecting the checkout process has been resolved and successfully retested.

---

## Why a TSR is Important

- Summarizes testing progress.
- Provides release recommendations.
- Tracks overall product quality.
- Helps project managers make informed decisions.

---

## Best Practices

- Include accurate test statistics.
- Highlight critical defects.
- Keep the report concise.
- Use professional language.
- Base recommendations on test results.

---

## Key Takeaway

A Test Summary Report communicates the overall quality of the software and supports informed release decisions.
