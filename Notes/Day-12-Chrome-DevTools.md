# Day 12 - Chrome DevTools

## What is Chrome DevTools?

Chrome DevTools is a built-in set of web development and debugging tools available in Google Chrome. QA Engineers use it to inspect web pages, identify issues, monitor network requests, and gather evidence for bug reports.

---

## Why QA Engineers Use DevTools

- Inspect HTML and CSS elements
- Identify JavaScript errors
- Monitor API requests and responses
- Verify cookies and browser storage
- Investigate performance issues
- Collect screenshots, console logs, and network logs for bug reports

---

- Elements
- Console

---

## Benefits for QA Engineers

- Speeds up bug investigation
- Improves communication with developers
- Provides technical evidence for bug reports
- Helps identify frontend and backend issues

---

## Key Takeaways

- Chrome DevTools is an essential tool for every QA Engineer.
- It helps investigate issues beyond what is visible on the UI.
- Understanding DevTools improves bug reporting and debugging skills.
