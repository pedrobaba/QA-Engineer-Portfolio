# Day 13 - API Testing Fundamentals

## What is an API?

API (Application Programming Interface) is a set of rules that allows two software applications to communicate with each other.

Example:

Frontend → API → Database

When a user logs into an application, the frontend sends a request to the API. The API processes the request, communicates with the database, and returns a response.

---

## Why is API Testing Important?

API testing verifies that the backend services work correctly before data reaches the user interface.

Benefits include:

- Faster than UI testing
- Detects backend issues early
- Validates business logic
- Ensures accurate data exchange
- Improves software reliability

---

## What QA Engineers Verify

- Correct HTTP status code
- Response time
- Response body
- Data accuracy
- Error handling
- Response headers

---

## API Testing Workflow

1. Send a request.
2. Receive a response.
3. Validate the status code.
4. Validate the response body.
5. Verify response time.
6. Report any defects found.

---

## Key Takeaways

- APIs connect different software systems.
- API testing focuses on backend functionality.
- Postman is one of the most popular API testing tools.
