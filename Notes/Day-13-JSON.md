# Day 13 - JSON

## What is JSON?

JSON (JavaScript Object Notation) is a lightweight data format used to exchange information between applications.

Most REST APIs return data in JSON format.

---

## Example

```json
{
  "userId": 1,
  "id": 1,
  "title": "Sample Title",
  "body": "Sample content"
}
```

---

## JSON Data Types

- String
- Number
- Boolean
- Object
- Array
- Null

---

## What QA Engineers Verify

- Required fields exist
- Correct data types
- Correct values
- No missing data
- Proper formatting

---

## Advantages

- Easy to read
- Lightweight
- Language-independent
- Widely supported

---

## Key Takeaways

Understanding JSON is essential for API testing because most modern web applications exchange data using JSON.
