# Day 13 - Postman

## What is Postman?

Postman is an API testing tool used to send HTTP requests and inspect responses.

It allows QA Engineers and Developers to test APIs without using a web browser.

---

## Features

- Send HTTP requests
- Create Collections
- Save Requests
- View Response Body
- View Headers
- View Response Time
- Automate API Testing

---

## Request Components

- URL
- HTTP Method
- Headers
- Body

---

## Response Components

- Status Code
- Response Body
- Response Headers
- Response Time

---

## Why QA Engineers Use Postman

- Validate APIs
- Test backend functionality
- Verify status codes
- Check response times
- Validate JSON data

---

## Key Takeaways

Postman simplifies API testing by providing an easy interface for sending requests and analyzing responses.
