# Day 13 - REST API

## What is REST?

REST (Representational State Transfer) is an architectural style used for building web services.

REST APIs communicate over HTTP using standard methods.

---

## HTTP Methods

| Method | Purpose |
|---------|---------|
| GET | Retrieve data |
| POST | Create new data |
| PUT | Replace existing data |
| PATCH | Update part of existing data |
| DELETE | Remove data |

---

## Common HTTP Status Codes

| Status Code | Meaning |
|------------|----------------------|
| 200 | OK |
| 201 | Created |
| 400 | Bad Request |
| 401 | Unauthorized |
| 403 | Forbidden |
| 404 | Not Found |
| 500 | Internal Server Error |

---

## REST Principles

- Client-Server Architecture
- Stateless Communication
- Uniform Interface
- Resource-Based URLs

Example Endpoint:

https://jsonplaceholder.typicode.com/posts/1

---

## Key Takeaways

- REST APIs use HTTP methods.
- Responses commonly return JSON.
- QA Engineers validate both request and response.
