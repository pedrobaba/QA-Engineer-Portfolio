# Day 16 - Postman Collections

## What is a Collection?

A Collection is a container that groups related API requests together in Postman. It helps QA engineers organize, manage, and execute API requests efficiently.

## Benefits of Collections

- Organizes related API requests.
- Makes testing easier.
- Allows requests to be reused.
- Simplifies collaboration.
- Supports running multiple requests together.

## Example Collection

QA Learning Collection

- Login API
- Get Users
- Create User
- Update User
- Delete User

## Why QA Engineers Use Collections

Collections help keep API testing structured, especially when working with large projects containing many endpoints.
