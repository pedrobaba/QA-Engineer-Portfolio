# 🔐 Day 17 – API Authentication

## What is Authentication?

Authentication is the process of verifying the identity of a user or application before allowing access to protected resources.

Authentication answers:

> **Who are you?**

### Common Authentication Methods

- Username and Password
- API Key
- Bearer Token
- Basic Authentication
- OAuth

---

## Why is Authentication Important?

API authentication helps prevent unauthorized users or applications from accessing protected resources.

It ensures that only properly authenticated clients can make certain requests.
