# Agile Sprint Simulation

## Project Overview

This project simulates how a QA Engineer works within an Agile Scrum team using Jira.

The application being tested is **Goal.com**, an e-commerce demo application used for practicing software testing.

The goal is to experience the complete software development lifecycle, from requirements analysis through bug reporting to sprint completion.

---

# Project Information

**Project Name:** Goal.com Testing Project

**Methodology:** Agile Scrum

**Sprint Duration:** 2 Weeks

**Team Size:** 6 Members

- 1 Product Owner
- 1 Scrum Master
- 2 Software Developers
- 1 UI/UX Designer
- 1 QA Engineer (Me)

---

# Sprint Goal

Deliver a stable user experience by testing the following features:

- User Login
- Homepage articles
- Favorite team
- Contact us
- Reset user password
- Change user email

# Sprint Backlog

During this sprint, the QA Engineer is responsible for:

- Reviewing user stories
- Creating test scenarios
- Writing test cases
- Executing manual tests
- Reporting bugs
- Retesting fixed defects
- Participating in Daily Stand-up meetings
