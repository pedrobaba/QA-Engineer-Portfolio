## 2. Testing Objectives

The objective was to evaluate the main functionality of SauceDemo, identify defects, and document testing outcomes.

The testing objectives included:

- Verify user login and authentication.
- Validate inventory and product information.
- Test product sorting.
- Verify shopping cart functionality.
- Validate checkout form fields.
- Check order summary and total calculations.
- Verify order completion and logout.

## 3. Testing Scope

### In Scope

- Checkout form validation
