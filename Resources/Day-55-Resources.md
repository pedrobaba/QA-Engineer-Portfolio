Day 55 — Security Testing Fundamentals

Official Learning Resources

1. OWASP Top 10
    https://owasp.org/www-project-top-ten/
    Use this resource to study common web application security risks.
2. OWASP Authorization Cheat Sheet
    https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html
    Review authorization checks and access-control principles.
3. OWASP API Security Top 10
    https://owasp.org/API-Security/
    Explore API security risks, including broken object-level authorization.
4. MDN — HTTP Response Status Codes
    https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status
    Review the meanings of HTTP status codes, including 401, 403, and 404.

Practice Tool

* Postman: https://www.postman.com/
    Use Postman to practice sending authenticated and unauthenticated requests in an authorized test environment.

Evidence and Verification Notes

Day 55’s test cases and security bug report were developed through scenario-based practice. No live application vulnerability was independently verified as part of this documentation.

Future practice should use authorized test environments, synthetic data, and redacted evidence.
