## Day 61 — Git & GitHub for QA

### Topics Practiced

- Git and GitHub fundamentals
- Working directory, staging area, local repository, and remote repository
- Essential Git commands
- Branches and pull requests
- Push rejections and merge conflicts
- Reviewing staged changes
- Clear commit messages

### Practice Reminder

Use `git status` to inspect repository state, stage only intended changes, and run `git diff --staged` before committing. Resolve conflicts carefully and preserve other contributors' work.
