## Day 65 — Test Coverage & Traceability Practice

### Topics Covered
- Requirement-to-test-case coverage
- Complete and partial requirement coverage
- Missing test coverage
- Forward and backward traceability
- Test execution coverage
- Test pass rate
- Coverage gaps and release risk

### Key Formulas

**Requirement linkage coverage**

`(Requirements with linked test cases / Total requirements) × 100`

**Complete requirement coverage**

`(Fully covered requirements / Total requirements) × 100`

**Test execution coverage**

`(Executed test cases / Total test cases) × 100`

**Test pass rate**

`(Passed test cases / Executed test cases) × 100`

### Important Distinctions
- Forward traceability: Requirement → Test Case.
- Backward traceability: Test Case → Requirement.
- A failed test case still counts as executed.
- A linked test case does not automatically establish complete requirement coverage.
- Coverage metrics should be interpreted alongside requirement importance and test quality.
