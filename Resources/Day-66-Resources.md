### Key Formulas

**Test pass rate**

`(Passed test cases / Executed test cases) × 100`

**Test execution coverage**

`(Executed test cases / Total test cases) × 100`

**Test failure rate**

`(Failed test cases / Executed test cases) × 100`

**Defect reopen rate**

`(Reopened defects / Closed defects) × 100`

**Defect fix rate**

`(Fixed and verified defects / Reported defects) × 100`

**Defect rejection rate**

`(Rejected defects / Submitted defects) × 100`

### Important Distinctions
- Failed test cases count as executed.
- Blocked and not-executed test cases are excluded from the executed-test denominator.
- Pass rate and execution coverage measure different things.
- Defect severity distribution helps communicate defect impact.
- A high pass rate does not automatically mean a release is safe.
- Defect trends should be interpreted in the context of testing scope and risk.
