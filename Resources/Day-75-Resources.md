## Day 75 — Test Summary Report

### Topics Covered

- Test Summary Report (TSR)
- Test execution metrics
- Execution rate, pass rate, failure rate and blocked rate
- Defect summary
- Severity vs priority
- Testing risks and limitations
- Release readiness assessment

### Key Learning

A Test Summary Report communicates the overall outcome of a testing cycle. It summarises execution results, defects, outstanding tests and risks to support informed release decisions.
