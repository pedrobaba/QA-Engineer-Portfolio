## Day 76 — QA Evidence and Documentation

### Topics Covered

- QA test evidence
- Screenshots and screen recordings
- Evidence naming conventions
- Evidence organisation
- Evidence traceability
- Linking evidence to test cases
- Linking evidence to bug reports
- API testing evidence
- QA portfolio documentation review

### Key Learning

Test evidence supports the results of software testing. Evidence should be genuine, clearly named, organised and traceable to the relevant test case or bug report.
