# 1. Objective

The objective of this test plan is to verify that the core functionalities of the SauceDemo web application work as expected and to identify, document, and report any defects that could negatively impact the user experience before release.

---

# 2. Scope

## In Scope

The following features will be tested:

- User Login
- Product Listing
- Product Sorting
- Add to Cart
- Remove from Cart
- Shopping Cart
- Checkout Process
- Logout

---

## Out of Scope

The following activities are not included in this testing cycle:

- Performance Testing
- Security Testing
- Database Testing
- API Testing
- Source Code Review

---

# 3. Test Approach

Testing will be performed manually using functional testing techniques.

The following testing types will be included:

- Functional Testing
- Smoke Testing
- Regression Testing
- Exploratory Testing
- Negative Testing
- Positive Testing

---

# 4. Test Environment

| Item | Details |
|------|---------|
| Website | https://www.saucedemo.com |
| Operating System | Windows 10 |
| Browser | Google Chrome (Latest Version) |
| Device | Desktop Computer |
| Internet | Stable Broadband Connection |

---

# 5. Entry Criteria

Testing will begin only when:

- Application is accessible.
- Test environment is available.
- Valid test credentials are available.
- Test data has been prepared.
- Test cases have been reviewed.

---

# 6. Exit Criteria

Testing will be completed when:

- All planned test cases have been executed.
- All Critical and High Severity defects have been resolved or accepted.
- Test Summary Report has been completed.
- No blocking issues remain.

---

# 7. Features to be Tested

### Login Module

- Valid Login
- Invalid Login
- Empty Username
- Empty Password
- Locked User

### Product Module

- View Products
- Product Details
- Product Sorting

### Shopping Cart

- Add Product
- Remove Product
- Cart Badge Update

### Checkout

- Customer Information
- Checkout Overview
- Order Completion

### Logout

- Successful Logout
- Session Handling

---

# 8. Features Not to be Tested

- Performance under heavy load
- Security vulnerabilities
- Database validation
- API functionality
- Browser compatibility outside Google Chrome

---

# 9. Risks

Possible risks include:

- Unstable internet connection.
- Test environment downtime.
- Limited testing time.
- Browser updates affecting test execution.
- Incomplete requirements.

---

# 10. Deliverables

The following documents will be produced:

- Test Plan
- Test Scenarios
- Test Cases
- Bug Reports
- Test Summary Report
- Learning Journal
